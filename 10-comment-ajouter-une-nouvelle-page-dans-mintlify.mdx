# Comment ajouter une nouvelle page dans Mintlify

### La méthode simple pour créer et afficher une nouvelle page

## Pourquoi ajouter une nouvelle page ?

Créer une nouvelle page permet d’étendre votre documentation, d’ajouter un tutoriel, une explication ou une référence.  

Mintlify facilite cette opération, mais il faut comprendre deux étapes essentielles :

1. créer la page  

2. l’ajouter dans la sidebar pour qu’elle soit visible  

Beaucoup de débutants oublient la deuxième étape.

## Comment créer une nouvelle page dans Mintlify ?

Dans votre projet Mintlify :

- ouvrez la sidebar  

- cliquez sur **New Page** ou **Add Page**  

- donnez un nom à votre page  

- Mintlify crée automatiquement un fichier `.mdx`  

Vous pouvez ensuite commencer à écrire votre contenu.

## Où se trouve la nouvelle page ?

Mintlify place automatiquement votre fichier dans le dossier prévu pour les pages.  

Selon votre configuration, cela peut être :

- `docs/`  

- `pages/`  

- ou un sous‑dossier spécifique  

La page existe, mais elle n’apparaît pas encore dans la navigation.

## Comment afficher la page dans la sidebar ?

Pour que votre nouvelle page soit visible dans le menu, vous devez l’ajouter dans la navigation.

Dans Mintlify :

- ouvrez l’onglet **Navigation**  

- choisissez la section où vous voulez placer la page  

- cliquez sur **Add Page**  

- sélectionnez votre nouvelle page  

Elle apparaît immédiatement dans la sidebar.

## Ajouter la page via mintlify.json

Si vous préférez modifier le fichier JSON :

- ouvrez `mintlify.json`  

- trouvez la section “navigation”  

- ajoutez votre page dans la liste correspondante  

C’est la méthode avancée, mais elle donne un contrôle total.

## Conseils pour bien organiser vos nouvelles pages

- placez chaque page dans la bonne section  

- utilisez un titre clair et court  

- évitez de créer trop de pages d’un coup  

- vérifiez que la page apparaît bien dans la sidebar  

- testez la navigation après chaque ajout  

Une documentation bien organisée est plus agréable à parcourir.

## Résumé

Créer une nouvelle page dans Mintlify est simple :  

vous la créez dans l’éditeur, puis vous l’ajoutez dans la sidebar pour qu’elle soit visible.  

Sans cette deuxième étape, la page existe mais reste cachée.
