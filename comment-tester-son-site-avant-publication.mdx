# Comment tester son site avant publication

### Vérifier que tout fonctionne avant d’envoyer vos modifications en ligne

## Pourquoi tester son site ?

Tester votre site avant publication permet :

- d’éviter les erreurs visibles par les visiteurs  

- de vérifier la mise en forme  

- de s’assurer que les liens fonctionnent  

- de repérer les problèmes de navigation  

- de corriger avant que ce soit en ligne  

C’est une étape essentielle pour une documentation propre et professionnelle.

## Tester dans l’éditeur Mintlify

Mintlify propose un aperçu intégré très pratique.

Dans l’éditeur :

- ouvrez la page que vous modifiez  

- regardez l’aperçu à droite  

- vérifiez les titres, paragraphes et listes  

- vérifiez que les blocs Mintlify s’affichent correctement  

- vérifiez que les images apparaissent  

L’aperçu Mintlify est fidèle à 95 % du rendu final.

## Tester la navigation interne

Avant de publier :

- cliquez sur les liens internes  

- vérifiez que chaque lien mène à la bonne page  

- testez la sidebar  

- vérifiez que les nouvelles pages apparaissent bien  

Une navigation cohérente est essentielle pour les utilisateurs.

## Tester les liens externes

Les liens externes doivent être vérifiés un par un :

- ouvrez chaque lien  

- vérifiez qu’il fonctionne  

- vérifiez qu’il mène à la bonne ressource  

- évitez les liens cassés ou obsolètes  

Un lien externe cassé donne une mauvaise impression.

## Tester après publication sur Vercel

Une fois publié :

- ouvrez votre site en ligne  

- rechargez la page modifiée  

- utilisez un rafraîchissement forcé si nécessaire  

- vérifiez l’affichage sur ordinateur et mobile  

- testez les images et les blocs visuels  

Vercel met à jour votre site en quelques secondes.

## Conseils pratiques

- testez toujours avant de publier  

- testez encore après la publication  

- vérifiez les pages liées à celle que vous modifiez  

- gardez un œil sur la cohérence générale  

- corrigez immédiatement les erreurs visibles  

Tester régulièrement évite les mauvaises surprises.

## Résumé

Tester son site avant publication consiste à vérifier l’aperçu Mintlify, la navigation, les liens, les images et le rendu final sur Vercel.  

Une bonne vérification garantit une documentation propre et professionnelle.
