# Foire aux questions (FAQ)

## Généralités

<Accordion title="Amuse est‑il vraiment gratuit ?">
Oui, Amuse est entièrement gratuit. Aucun abonnement, aucune carte bancaire, aucune limite de génération. Vous pouvez l’utiliser sans aucune contrepartie.
</Accordion>

<Accordion title="Faut‑il une connexion Internet pour utiliser Amuse ?">
Non, après l’installation initiale des modèles (téléchargement unique), Amuse fonctionne **totalement hors ligne**. Aucune donnée n’est envoyée sur Internet.
</Accordion>

<Accordion title="Amuse existe‑t‑il sur Mac ou Linux ?">
Actuellement, Amuse est disponible uniquement sur **Windows**. Une version Linux est envisagée mais pas encore annoncée. Sur Mac, il n’y a pas de portage prévu.
</Accordion>

<Accordion title="Est‑ce que je peux utiliser Amuse sur un PC non‑AMD ?">
Oui, Amuse fonctionne sur n’importe quel PC Windows (Intel, NVIDIA, AMD). Cependant, les optimisations matérielles (NPU, GPU EP) sont spécifiques aux composants AMD. Sur du matériel concurrent, les performances seront moins bonnes.
</Accordion>

## Installation et configuration

<Accordion title="Quels sont les prérequis matériels ?">
- **Minimale** (très lent) : CPU 4 cœurs, 8 Go RAM, 20 Go disque.
- **Recommandée** : AMD Ryzen AI 300 / 8040 avec 24-32 Go RAM, ou Radeon RX 7000/9000 avec 16 Go RAM.
- **Optimale** : Ryzen AI Max+ 395 ou Radeon RX 9070 XT avec 32-64 Go RAM.

Consultez la [page de compatibilité](/ia/Amd-Amuse/resources/hardware-compatibility) pour plus de détails.
</Accordion>

<Accordion title="Que faire si le driver AMD ne détecte pas mon NPU ?">
Sur les Ryzen AI 8040 series, une mise à jour OEM (MCDM et NPU driver) est obligatoire. Contactez le support de votre fabricant (Asus, Lenovo, etc.). Sur Ryzen AI 300 series, le NPU est normalement reconnu automatiquement avec le dernier driver Adrenalin.
</Accordion>

<Accordion title="Puis‑je installer les modèles sur un autre disque ?">
Oui. Dans Amuse, allez dans **Settings** → **Default model directory** et choisissez un dossier sur un autre disque (ex: D:AmuseModels).
</Accordion>

## Utilisation

<Accordion title="Comment obtenir des résultats de meilleure qualité ?">
- Utilisez le curseur **Performance** sur **Quality**.
- Augmentez le nombre d’étapes (steps) à 30-40 (Mode Expert).
- Choisissez un modèle plus puissant (SD 3.5 Large, Flux.1).
- Affinez votre prompt avec des mots-clés comme “photographique”, “haut détail”, “8K”.
</Accordion>

<Accordion title="Pourquoi mes images mettent‑elles longtemps à générer ?">
Cela dépend de votre matériel :
- **CPU seul** : très lent (plusieurs minutes par image).
- **GPU Radeon d’entrée de gamme** (RX 6400/6500) : 30-60 secondes.
- **Radeon RX 7800 XT ou supérieure** : 5-15 secondes en mode Balanced.
- **Ryzen AI avec NPU** : 10-20 secondes.

Passez en mode **Fast** pour accélérer.
</Accordion>

<Accordion title="Puis‑je générer des vidéos plus longues que 4 secondes ?">
Actuellement, la génération vidéo est limitée à environ 96 frames (4 secondes à 24 fps) en raison de la consommation VRAM. Les futures versions (WAN, LTX-2) pourront produire des séquences plus longues.
</Accordion>

## Modèles

<Accordion title="Où trouver des modèles supplémentaires ?">
- **Bibliothèque intégrée** d’Amuse (Model Manager) : plus de 100 modèles (SDXL Turbo, Dream Shaper, Realistic Vision, etc.).
- **Hugging Face** : [collection AMD](https://huggingface.co/collections/amd/amdgpu-onnx-675e6af32858d6e965eea427) (modèles `_amdgpu`) et des milliers d’autres (format ONNX ou GGUF).
</Accordion>

<Accordion title="Quelle est la différence entre les modèles normaux et les modèles _amdgpu ?">
Les modèles `_amdgpu` sont optimisés par AMD pour les GPU Radeon et NPU Ryzen AI (flash attention, élagage, fusion d’opérateurs). Ils sont jusqu’à 4,3× plus rapides et consomment jusqu’à 2× moins de mémoire. Utilisez‑les si vous avez du matériel AMD récent.
</Accordion>

<Accordion title="Puis‑je importer un modèle safetensors (PyTorch) ?">
Non, Amuse attend des modèles au format **ONNX** ou **GGUF**. Vous pouvez convertir un modèle PyTorch en ONNX via Microsoft Olive ou l’outil AMD Optimizer.
</Accordion>

## Dépannage

<Accordion title="J’ai une erreur “Out of memory” même avec un modèle léger">
- Fermez toutes les autres applications (navigateur, jeux).
- Baissez la résolution à 512×512.
- Passez en mode **Fast**.
- Dans les paramètres avancés, réduisez le nombre d’images générées en parallèle (`Image Count` = 1).
- Si vous avez un GPU avec moins de 8 Go VRAM, utilisez les modèles `_amdgpu` qui consomment moins de mémoire.
</Accordion>

<Accordion title="L’option AMD XDNA Super Resolution est grisée">
Cette fonction n’est disponible que sur les processeurs **Ryzen AI 300 series** et **8040 series** (avec driver à jour). Vérifiez que votre NPU est bien reconnu (Gestionnaire de périphériques → Processeurs → AMD NPU).
</Accordion>

<Accordion title="Le mode Expert ne s’affiche pas ?">
Cliquez sur le bouton **“Expert Mode”** en bas à gauche de l’interface. Si le bouton est absent, vous utilisez peut-être une version antérieure à Amuse 2.0. Mettez à jour.
</Accordion>

## Confidentialité et données

<Accordion title="Mes images sont‑elles envoyées à AMD ou à des serveurs ?">
Non, tout est **local**. Aucune image, aucun prompt ne quitte votre ordinateur. Amuse ne contient aucun tracker ni télémétrie obligatoire (seulement des rapports d’erreur anonymes optionnels).
</Accordion>

<Accordion title="Amuse collecte‑t‑il des données personnelles ?">
Selon la politique de TensorStack, seules des données de diagnostic (crash logs, version du driver) peuvent être envoyées avec votre consentement. Aucune donnée personnelle n’est collectée. Consultez le [Privacy Policy](https://www.tensorstack.ai/privacy) pour plus de détails.
</Accordion>

## Compatibilité

<Accordion title="Amuse fonctionne‑t‑il avec une carte graphique NVIDIA ?">
Oui, via le backend DirectML. Cependant, les performances seront inférieures à celles d’un GPU AMD équivalent et vous ne bénéficierez pas des optimisations `_amdgpu`. Pour du matériel NVIDIA, préférez des outils comme ComfyUI ou Automatic1111.
</Accordion>

<Accordion title="Puis‑je utiliser Amuse sur un PC portable avec batterie ?">
Oui, mais la génération consomme de l’énergie. Sur batterie, Amuse réduit automatiquement la fréquence pour économiser. Les performances seront moindres. Pour des sessions longues, branchez l’alimentation.
</Accordion>

## Mises à jour

<Accordion title="Comment mettre à jour Amuse ?">
Téléchargez la dernière version depuis [amuse-ai.com](https://www.amuse-ai.com) et installez‑la par-dessus l’ancienne. Vos modèles installés seront conservés.
</Accordion>

<Accordion title="Où trouver les notes de version ?">
Les notes de version sont publiées sur le [blog AMD](https://www.amd.com/en/blogs) (rechercher “Amuse”) et sur le [dépôt GitHub](https://github.com/TensorStack-AI/AmuseAI/releases).
</Accordion>
