## Pourquoi ces modèles sont plus rapides ?

Les optimisations appliquées par AMD (via Microsoft Olive et l’AMD Model Optimizer) incluent :

- **Flash Attention** : réduction des accès mémoire dans les blocs d’attention (jusqu’à 2× moins de VRAM).
- **Fusion d’opérateurs** : combinaison de plusieurs opérations en une seule (ex: layer norm + activation).
- **Élagage des poids** (pruning) : suppression des neurones peu importants, sans perte de qualité notable.
- **Utilisation des cœurs WMMA** : les matrices sont traitées par les accélérateurs matériels des RDNA 3/4 (Wave Matrix Multiply Accumulate).
- **Support de la parcimonie structurée 4:2** (sur RDNA 4) : doublement des performances pour certaines opérations.

<Accordion title="Flash Attention en détail">
  L’attention est le goulot d’étranglement principal des transformeurs. La flash attention évite de matérialiser toute la matrice d’attention en mémoire, ce qui réduit la bande passante et permet des lots plus grands. Les modèles `_amdgpu` intègrent cette optimisation nativement.
</Accordion>

## Comment les installer dans Amuse ?

1. Ouvrez **Mode Expert**.
2. Allez dans **Model Manager**.
3. Cliquez sur **Install** → **From Hugging Face**.
4. Copiez l’identifiant du modèle (ex: `amd/sd3.5_large_amdgpu`).
5. Sélectionnez le format **ONNX** (recommandé).
6. Cliquez sur **Download**.
7. Une fois téléchargé, le modèle est automatiquement optimisé pour votre matériel.

<Info>
  La première optimisation peut prendre plusieurs minutes. Les versions suivantes utiliseront le cache.
</Info>

## Utilisation dans d’autres applications

Les modèles `_amdgpu` sont des modèles ONNX standard. Vous pouvez donc les utiliser en dehors d’Amuse, avec :

- **ONNX Runtime** (avec le provider ROCm ou DirectML).
- **ComfyUI** (via le plugin ONNX).
- **Python** (via `onnxruntime`).

Exemple en Python : créez une session avec `ort.InferenceSession("sd3.5_large_amdgpu.onnx", providers=["ROCMExecutionProvider"])` puis exécutez l’inférence.

## Dépannage

| Problème | Solution |
|----------|----------|
| Le modèle `_amdgpu` ne s’affiche pas dans la liste | Vérifiez que vous avez bien tapé l’identifiant exact (amd/...). Certains modèles sont en accès restreint ; connectez-vous à Hugging Face. |
| Erreur “Provider not available” | Installez le driver AMD avec l’option **AI Bundle** (voir [guide d’installation](/ia/Amd-Amuse/getting-started/installation)). |
| L’optimisation échoue avec “out of memory” | Libérez de la RAM (fermez les navigateurs). Baissez la résolution par défaut du modèle (dans les paramètres) avant optimisation. |
| Les performances sont moins bonnes qu’annoncé | Vérifiez que vous utilisez bien le backend ROCm (sur Radeon) ou le NPU (sur Ryzen AI). Dans Amuse, allez dans Settings → Execution Device et sélectionnez AMDGPU ou NPU. |
