# Ingénierie du prompt

Le **prompt** est la description textuelle de l’image que vous voulez générer. Bien le formuler est la clé pour obtenir un résultat satisfaisant. Ce guide vous donne des techniques simples mais puissantes.

## Structure de base d’un bon prompt

Un prompt efficace contient généralement trois éléments :

1. **Sujet** : ce que vous voulez voir (personne, objet, animal, paysage).
2. **Contexte / environnement** : où se trouve le sujet, décor, éclairage.
3. **Style / qualité** : photographique, peinture, cartoon, cyberpunk, réaliste, etc.

Exemple : `“un chat noir aux yeux verts assis sur un canapé rouge, salon moderne, lumière naturelle, style photographique haute résolution”`

## Mots-clés utiles

### Pour la qualité / résolution

- `haute résolution`, `8K`, `net`, `détaillé`
- `photo réaliste`, `cinématographique`, `professionnel`

### Pour le style artistique

- `peinture à l’huile`, `aquarelle`, `croquis`, `manga`, `cyberpunk`, `steampunk`, `fantasy`, `science-fiction`

### Pour l’éclairage

- `lumière naturelle`, `soleil couchant`, `néon`, `contre-jour`, `studio lighting`

### Pour la composition

- `plan large`, `gros plan`, `portrait`, `vue aérienne`, `symétrique`

### Négatif (ce que vous ne voulez pas)

Dans le Mode Expert, vous pouvez ajouter un **negative prompt** (par exemple : `flou, déformé, doigts en trop, moche`).

## Exemples de prompts pour différents usages

### Portrait réaliste

`“portrait d’une femme âgée souriant, rides visibles, éclairage doux, fond flou, photographie professionnelle, Canon 85mm f/1.4”`

### Paysage fantastique

`“château flottant dans les nuages, cascades d’eau cristalline, montagnes enneigées au loin, style peinture numérique, couleurs pastel, lumière dorée”`

### Objet design

`“une chaise futuriste en verre et carbone, fond blanc minimaliste, rendu 3D photoréaliste, 8K, éclairage d’atelier”`

### Animal (cartoon)

`“un panda roux joueur tenant une tasse de thé, style animation Disney, couleurs chaudes, fond de forêt enchantée”`

## Dos and Don’ts

| À faire | À éviter |
|---------|----------|
| Décrire précisément (couleurs, formes, textures) | Être trop vague (“une belle image”) |
| Utiliser des adjectifs qualitatifs (net, réaliste) | Accumuler des mots contradictoires |
| Préciser l’éclairage et l’ambiance | Oublier le contexte |
| Tester plusieurs variantes | Rester bloqué sur un prompt inefficace |

## Itérer pour améliorer

Si le résultat ne vous satisfait pas, modifiez progressivement le prompt :

1. Changez un adjectif (`“réaliste”` → `“hyper‑réaliste”`).
2. Ajoutez un mot-clé de style (`“cinématographique”`).
3. Précisez les couleurs (`“rouge vif”` plutôt que `“rouge”`).
4. Utilisez le negative prompt pour éliminer les défauts récurrents.

## Utiliser les modèles spécialisés

Certains modèles répondent mieux à des styles particuliers :

| Modèle | Idéal pour |
|--------|------------|
| Dream Shaper | Illustrations, manga, cartoon |
| Realistic Vision | Photos réalistes, portraits |
| SDXL Turbo | Généraliste, rapide |
| SD 3.5 Large | Scènes complexes, haute qualité |
| Flux.1 | Photoréalisme extrême, 8K |

<Info>
  Pour un portrait réaliste, utilisez **Realistic Vision** ou **Flux.1**. Pour un personnage de bande dessinée, préférez **Dream Shaper**.
</Info>

## Longueur du prompt

- **Très court** (quelques mots) : l’IA interprète librement, peut donner des surprises.
- **Moyen** (15-30 mots) : bon compromis pour la plupart des cas.
- **Très long** (paragraphe) : utile pour des scènes complexes, mais peut ralentir la génération.

## Exemples comparatifs

| Prompt | Résultat attendu |
|--------|------------------|
| `“chat”` | N’importe quel chat, style variable |
| `“chat siamois allongé sur un canapé”` | Chat spécifique, contexte clair |
| `“chat siamois allongé sur un canapé rouge, style peinture à l’huile, éclairage chaleureux, impressionnisme”` | Résultat très contrôlé |

## Expérimentez avec les seeds

Dans le Mode Expert, fixez une graine (seed) pour reproduire exactement la même composition, puis variez le prompt. Cela vous aide à comprendre l’impact de chaque mot.

## Ressources supplémentaires

- [Lexica](https://lexica.art/) : base de millions de prompts d’exemples.
- Communauté Discord d’Amuse : échangez des prompts avec d’autres utilisateurs.

## En résumé

- Un bon prompt est **précis** et **contextualisé**.
- Ajoutez des mots-clés de **style** et de **qualité**.
- **Itérez** : améliorez pas à pas.
- Adaptez le **modèle** à l’effet recherché.

N’ayez pas peur de tester des prompts absurdes ou créatifs – l’IA surprend parfois.
