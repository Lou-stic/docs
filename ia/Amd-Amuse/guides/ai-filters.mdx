# Filtres IA et transformation d'images

Les **AI Filters** d’Amuse permettent de transformer une photo ou un dessin existant en lui appliquant un style génératif (cyberpunk, réaliste, artistique, etc.). Tout se fait localement, sans envoyer votre image à un serveur.

## Accès à la fonction

Dans l’interface principale, cliquez sur l’onglet **“AI Filters”**. Vous arrivez sur un espace dédié.

<Figure src="/images/amuse-ai-filters.png" caption="L’interface des AI Filters" />

## Charger une image source

- Cliquez sur **“Load Image”** ou glissez-déposez une image depuis votre ordinateur.
- Recadrez l’image si nécessaire (outil de crop).
- L’image apparaît dans la zone de travail.

## Les paramètres essentiels

### Prompt

Décrivez le style que vous souhaitez appliquer. Exemples :

- `“cyberpunk style, néons, ambiance futuriste”`
- `“peinture à l’huile, couleurs vives, impressionnisme”`
- `“croquis au crayon, noir et blanc”`

### Presets

Quatre préréglages sont disponibles :

| Preset | Effet |
|--------|-------|
| **Artistic Transform** | Transformation artistique libre |
| **Realistic Blend** | Mélange réaliste, peu de déformation |
| **Sketch to Drawing** | Transforme une photo en dessin au trait |
| **Color Transform** | Change la palette de couleurs sans altérer les formes |

### Sliders

Deux curseurs permettent d’affiner le résultat :

- **Image Blend** : de 0 (seulement le style) à 1 (seulement l’image originale). Une valeur de 0,6 à 0,8 donne un bon équilibre.
- **AI Assistant** : contrôle l’intensité de l’interprétation par l’IA. Plus la valeur est haute, plus l’IA s’éloigne de l’original.

<Info>
  **Astuce** : commencez avec Image Blend à 0,7 et AI Assistant à 0,5, puis ajustez selon le rendu.
</Info>

## Générer et choisir

- Cliquez sur **“Generate Images”** (par défaut, 4 variations sont produites).
- Attendez quelques secondes (le temps dépend de votre matériel et du modèle utilisé).
- Sélectionnez l’image qui vous plaît et sauvegardez-la (bouton “Save”).

## Modèles utilisés

Les AI Filters s’appuient sur des modèles **SDXL Lightning** combinés à des Control Nets (canny, openpose, etc.). Ces modèles sont optimisés pour AMD et offrent un bon compromis vitesse/qualité.

<Warning>
  Si vous n’avez pas encore téléchargé de modèle pour les filtres, Amuse vous proposera automatiquement d’en installer un lors de la première utilisation. Acceptez.
</Warning>

## Exemple concret

Supposons que vous chargiez une photo de portrait. Vous voulez un effet **cyberpunk** :

1. Prompt : `“cyberpunk style, lumières néon, ambiance nocturne”`
2. Preset : `Artistic Transform`
3. Image Blend : `0,65`
4. AI Assistant : `0,6`
5. Générez 4 images.

Le résultat mêle les traits du visage d’origine avec des éléments cyberpunk (lumières, reflets colorés). Vous pouvez ensuite régler les sliders pour que le visage reste plus ou moins reconnaissable.

## Dépannage

| Problème | Solution |
|----------|----------|
| L’image transformée ressemble peu à l’originale | Augmentez **Image Blend** (vers 0,8-0,9) |
| L’effet est trop faible | Baissez **Image Blend** (vers 0,4-0,5) et augmentez **AI Assistant** |
| Résultats déformés, visages étranges | Le modèle utilisé n’est pas adapté aux portraits. Essayez le preset “Realistic Blend” |
| Génération lente | Utilisez un modèle plus léger (SDXL Turbo) via le Model Manager |

## Utilisation avancée : Design et sketch

Dans l’onglet **“Design”** (accessible depuis le Mode Expert), vous pouvez partir d’un croquis grossier :

- Dessinez quelques formes (rivière, montagnes, personnage) avec les outils de pinceau.
- Ajoutez un prompt décrivant la scène.
- Cliquez sur **“Generate”**. L’IA remplit les détails en suivant votre tracé.

Le curseur **“Overlay”** permet de voir l’influence de votre dessin sur le résultat final. Cette fonction est idéale pour la conception d’environnements ou de compositions.

## Résumé

- Les AI Filters transforment vos photos en leur appliquant un style génératif.
- Les sliders **Image Blend** et **AI Assistant** sont les clés du contrôle.
- Utilisez les presets comme point de départ.
- La fonction **Design** (sketch) permet de guider l’IA par un dessin simple.

Pour aller plus loin, consultez le [guide sur la génération d’images](/ia/Amd-Amuse/guides/image-generation) et le [Mode Expert](/ia/Amd-Amuse/guides/advanced-mode).
