# Première génération d'image

Ce guide pas à pas vous montre comment générer votre première image avec Amuse, de l’installation à l’enregistrement du résultat.

## Avant de commencer

- Amuse est installé (voir [guide d’installation](/ia/Amd-Amuse/getting-started/installation)).
- Vous avez une connexion Internet pour le premier téléchargement du modèle (ensuite, tout fonctionne hors ligne).

## Étape 1 : Lancer Amuse et choisir le Mode EZ

Par défaut, Amuse s’ouvre en **Mode EZ** (mode simplifié). C’est parfait pour débuter.

Si vous êtes en Mode Expert, basculez en cliquant sur le bouton **“EZ Mode”** en bas à gauche.

## Étape 2 : Écrire un prompt (votre idée)

Dans le champ **“Prompt”**, décrivez simplement l’image que vous voulez. Par exemple :

`un paysage de montagne au coucher du soleil, style réaliste`

<Info>
**Astuce** : restez simple pour la première fois. Vous pourrez ensuite affiner avec des mots-clés comme “photographique”, “peinture à l’huile”, “cyberpunk”, etc.
</Info>

## Étape 3 : Choisir le niveau de performance

Utilisez le curseur **Performance** :

- **Fast** : génération rapide, qualité moindre – idéal pour tester des idées.
- **Balanced** : bon compromis (recommandé pour commencer).
- **Quality** : plus lent, mais meilleure qualité.

Laissez-le sur **Balanced** pour l’instant.

## Étape 4 : Lancer la génération

Cliquez sur le bouton **“Generate”** (générer).

- La première fois, Amuse va **télécharger automatiquement** un modèle de base (généralement SDXL Turbo). Cela peut prendre quelques minutes selon votre connexion.
- Une fois le modèle téléchargé, une **optimisation** est lancée (préparation du modèle pour votre matériel). Cela peut prendre 2 à 5 minutes.
- Ensuite, les images apparaissent les unes après les autres.

<Warning>
**Si vous avez un message “out of memory”** : baissez la résolution dans les paramètres avancés (par exemple 512×512) ou passez en mode “Fast”.
</Warning>

## Étape 5 : Visualiser et sauvegarder

Quatre images sont générées par défaut. Cliquez sur celle que vous préférez.

- **Sauvegarder** : bouton “Save Image” → choisissez un dossier sur votre PC.
- **Recréer** : bouton “Regenerate” pour obtenir des variantes.
- **Supprimer** : corbeille à côté de l’image.

## Étape 6 : Expérimenter

Une fois votre première image réussie, amusez-vous à changer le prompt, le nombre d’images (`Image Count`), le format (`Aspect Ratio`), et le curseur de performance.

## Dépannage rapide

| Problème | Solution |
|----------|----------|
| Rien ne se passe quand je clique sur Generate | Vérifiez que vous avez une connexion Internet (pour le premier téléchargement). Redémarrez Amuse. |
| Les images sont floues | Augmentez la qualité (curseur vers Quality) ou choisissez un modèle plus récent dans le Model Manager (ex: SD 3.5 Large). |
| La génération est très lente | Passez en mode “Fast” ou installez un modèle plus léger (SDXL Turbo). Sur un vieux PC, utilisez le CPU (lent, mais ça marche). |

## Prochaine étape

Maintenant que vous avez généré votre première image, découvrez comment [utiliser les filtres AI](/ia/Amd-Amuse/guides/ai-filters) pour modifier des photos existantes, ou apprenez à [maîtriser les paramètres avancés](/ia/Amd-Amuse/guides/image-generation) .
